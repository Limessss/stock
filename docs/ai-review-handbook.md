# 完整情绪周期操作手册

## 一、完整周期与赚钱效应的定义

**启动点 → 转一 → 转二 → 三阶段 → 下跌一 → 下跌二 → 新启动点**

> [!abstract] 周期总纲
> **启动看新方向和试错，转一看确认与分歧转强，转二看赚钱效应扩散，三阶段看一致加速赶顶与买点消失，下跌一看亏钱效应爆发，下跌二看亏钱效应衰竭和新周期孕育。**

本手册采用上述个人交易体系的阶段划分。以下强弱比较是体系内的定性判断，不是经过统计验证的收益排名；阶段需要用当时可见的盘面持续确认，不能靠事后涨跌倒推。

### 1. 赚钱效应的统一定义

**赚钱效应**：资金能在有承接、有明确失效条件的买点实际参与，买入后容易获得溢价；判断稍有偏差时，仍较常出现修复和退出机会。全文统一按这一标准判断赚钱效应强弱。

因此，判断赚钱效应不能只数涨停，也要看：**能不能买到合适的位置，买完有没有正反馈，分歧后有没有修复。**

> [!important] 核心结论
> **在本体系中，转二是赚钱效应最强、买点质量和容错率最高的阶段。**
> **三阶段赚钱效应下降，买点质量和容错率转弱。**核心趋向一字、缩量、连续加速赶顶，舒服买点逐渐消失，不能因盘面亢奋而提高进攻力度。

### 2. 各阶段对照表

下表是同一周期内的相对比较。“容错率高”指修复和退出机会相对较多，不代表买错必然解套。

| 阶段 | 赚钱效应 | 买点质量 | 容错率 | 核心特征 |
| --- | --- | --- | --- | --- |
| 启动点 | 初现，尚不稳定 | 有空间，确认不足 | 较低 | 新方向主动，低仓试错，等待持续性 |
| 转一 | 增强，开始扩散 | 高，重在确认后的分歧转强 | 提升 | 方向获得认可，核心逐渐明确 |
| 转二 | **最强，正反馈持续扩散** | **最高，核心仍有正常换手和分歧买点** | **最高，相对容易出现修复** | **核心有买点、买完有溢价、错了有修复** |
| 三阶段 | **下降，优质参与机会减少** | 低，舒服买点消失 | 下降 | 核心一字、缩量、连续加速赶顶；场外资金转向补涨、后排和弱转强 |
| 下跌一 | 很弱，负反馈集中爆发 | 很低，抄底易失效 | 低 | 强股也开始亏钱，分歧无法有效修复 |
| 下跌二 | 弱，局部新方向开始试探 | 整体有限，新方向待确认 | 仍低，随亏钱效应衰竭逐步改善 | 极端负反馈减少，新周期孕育 |

### 3. 使用原则

- **启动点重试错，转一、转二重确认后的进攻，三阶段转向持仓管理，下跌阶段重防守。**
- 阶段不由固定板数或上涨天数决定，也不要求每轮行情完整、依次走完。
- 市场整体、题材和个股可能处于不同阶段。先判断所交易主线的周期，再检查市场整体负反馈是否构成约束。
- 阶段标签不能替代具体买点和退出条件；出现相反证据，应及时修正判断。

## 二、六个阶段的操作规则

### 1. 启动点：看新方向和试错

**阶段定义：**旧周期亏钱效应开始缓和，新方向出现局部正反馈，但主线与核心尚未充分确认。市场从无人关注走向初步试探。

**典型信号：**

- 老周期高位风险已有较多释放，核按钮和极端负反馈减少。
- 新题材出现批量首板，部分股票主动于指数和板块。
- 出现有带动性的品种或容量核心，但市场共识尚低。

**操作重点：**关注新题材第一批主动涨停、有带动性的首板或1进2、容量核心及与指数共振的方向，以小仓取得观察权。次日检查核心溢价、首板晋级、板块扩散和新增助攻，持续正反馈才支持提高参与程度。

**避免：**把旧龙头反抽直接视作新周期启动；把单只股票涨停当成主线确立。

**仓位思路：**低仓试错，随证据增强逐步提高；赔率可能有吸引力，但确定性和容错率仍低。

### 2. 转一：看确认与分歧转强

**阶段定义：**新方向连续获得资金认可，赚钱效应从少数个股向板块扩散，市场开始确认主线，核心逐渐明确。情绪由怀疑转向认可。

**典型信号：**

- 核心连续晋级或持续获得溢价，板块不断补充首板和助攻。
- 资金向主线流入，分歧后出现主动承接和回流。
- 核心修复能带动板块，正反馈具有延续性。

**操作重点：**关注核心第一次有效分歧、分歧转强、有带动性的卡位、主线容量核心，以及符合主线逻辑的1进2或2进3。

典型的弱转强，是前一天炸板、烂板或板块分化后，次日出现超预期表现、实际承接、主动修复和板块回流。**竞价强只是线索，后续承接与带动性才是确认的重要部分。**

**避免：**单纯因核心涨过几个板就去买缺乏辨识度的后排；只凭高开认定弱转强成立。

**仓位思路：**启动逻辑与分歧修复得到验证后，可从试错逐步转向进攻；没有确认则继续保留试错尺度。

### 3. 转二：看可参与赚钱效应的持续扩散

**阶段定义：**主线和核心已基本确认，市场持续奖励有效参与，核心仍提供正常换手、分歧和承接买点。赚钱效应能从龙头传向容量核心、前排及有质量的板块助攻，是本体系中买点质量和容错率最高的阶段。

> [!tip] 转二的三个关键观察
> **核心有买点：**分歧有承接，换手后仍能走强，有可执行的参与位置和失效条件。
> **买完有溢价：**此前真实可参与的买点，后续持续获得正反馈，而非只有买不到的一字板上涨。
> **错了有修复：**部分炸板或分歧股仍有修复、退出机会，亏钱效应没有系统性扩散；这不是持有错误交易等待解套的理由。

**典型机会：**

- 核心分歧 → 承接 → 回封 → 后续溢价。
- 板块分歧 → 核心抗跌 → 板块回流。
- 核心正常换手晋级，同时其他有效参与也能获得正反馈。

**操作重点：**从寻找方向转向聚焦已确认的高辨识度核心、有带动性的卡位及强容量核心；观察板块回流时谁先被选择。

**去弱留强仍然必要：**赚钱效应扩散不等于所有股票普涨，后排仍可能淘汰。应减少随机首板、无辨识度中位股和纯跟风。但如果只剩少数买不到的核心上涨，其他可参与品种普遍失去溢价，就不能继续仅凭“核心强”判为健康转二。

**避免：**把“第一次大分歧”自动当成买点。必须看承接、修复和板块反馈；高潮后的大分歧不能套用转二逻辑。

**仓位思路：**在买点和正反馈有效时保持进攻，减少无效持仓、聚焦核心；容错率高也不能替代退出纪律。

### 4. 三阶段：看一致加速赶顶与买点消失

**阶段定义：**主线进入高度一致，核心趋向一字、缩量和连续加速赶顶。资金越来越难获得有质量的买点，赚钱效应与容错率下降。

**典型信号：**

- 核心接连加速，正常换手、分歧承接的买点减少。
- 核心看似强势，但优质买点难以参与，资金开始转向边缘品种。
- 补涨、后排、“龙二龙三”以及弱转强叙事增多。
- 买得到的品种后续溢价变差，开板后承接与修复不如转二。

补涨和后排扩散本身不足以判定三阶段。要结合**核心买点消失、场外参与质量下降和一致加速**一起判断。

#### 核心纪律：适用于三阶段后半场

以下三条禁做纪律限定在**三阶段后半场**。三阶段前半场仍按实际买点、承接和后续溢价判断，不能直接套用后半场的禁做结论。

后半场不按固定天数划分，可结合核心持续加速后买点进一步减少、补涨与后排溢价衰减、分歧修复变弱等信号辅助识别；不能仅凭核心一字或出现补涨就认定。

1. **不做三阶段后半场的补涨。**个股位置低，不代表所处周期位置低；补涨可能承接的是核心买不到后的外溢资金，不能仅凭低位推定安全。
2. **不做三阶段后半场的弱转强。**高潮后的修复可能只是最后一次一致，不能照搬转一的分歧确认逻辑。
3. **三阶段后半场，不因核心买不到而降低标准去做后排。**资金撤退时，后排承接和退出机会可能迅速恶化。

**操作重点：**从寻找新买点转向处理已有持仓，去弱留强、按计划兑现，观察核心加速后的承接和板块反馈，防止高潮后的大分歧吞噬浮盈。

**仓位思路：**主动降低风险暴露。没有合适买点可以不参与，不因核心继续加速而追买。连续加速提示进入赶顶风险区，并不能据此精确预测哪一天见顶。

### 5. 下跌一：看亏钱效应爆发

**阶段定义：**赚钱效应系统性转弱，负反馈集中爆发并扩散，原来有效的分歧修复开始失效。

**典型信号：**

- 核心断板后无法有效修复，高位股批量炸板。
- 天地板、中位股核按钮增多，补涨集中走弱。
- 昨日最强、昨日涨停也开始让可参与资金明显亏钱。
- 修复短暂且不能带动板块，反而出现新的负反馈。

**最大陷阱：**因为转二时分歧常能修复，就认为本次下跌也会同样修复。核心断板本身不是充分证据，重点在于修复是否失效、亏钱效应是否扩散。

**操作重点：**检查“昨天最强的股票，今天还能不能给溢价”，并结合高位、中位和补涨的反馈判断退潮范围。

**避免：**随意第一次抄底、高位弱转强、高位反包、中位股修复、老龙反抽和补涨博弈。

**仓位思路：**大幅降低仓位，必要时空仓；核心任务是保存资金和交易状态。

### 6. 下跌二：看亏钱效应衰竭和新周期孕育

**阶段定义：**旧周期经过较多风险释放，接力意愿和高度下降，极端负反馈逐渐减少。市场整体仍难做，但新方向可能开始摆脱旧周期影响。

**典型信号：**

- 老龙明显回撤，中位股退场，旧主线关注度下降。
- 接力谨慎，情绪低迷，但核按钮和新增极端亏损减少。
- 部分新题材、新首板或容量品种开始逆势主动。

**操作重点：**观察“谁开始不跟跌”，尤其是旧周期继续弱、新方向却出现批量首板、连板、助攻和次日溢价的情况。指数共振和与旧主线不同的方向值得跟踪，但仍须验证持续性。

**避免：**把跌得久、跌得多等同于风险出清；把一个涨停当成新周期确认。亏钱效应缓和不等于赚钱效应已经恢复。

**仓位思路：**以空仓或极低仓位观察，只有新方向出现实际正反馈时，才恢复小仓试错，等待下跌二向新启动点过渡。

## 三、周期切换信号

真正重要的是识别周期正在往哪里走，再据此调整行动。

| 切换 | 重点观察 | 核心变化 |
| --- | --- | --- |
| 启动点 → 转一 | 首板持续溢价，核心晋级，板块新增助攻，新方向连续获得认可 | 从局部试错转向方向确认 |
| 转一 → 转二 | 主线与核心清晰，分歧有承接，可参与交易持续获得溢价，正反馈扩散 | 从确认方向转向可参与赚钱效应充分展开 |
| 转二 → 三阶段 | 核心趋向一字、缩量和连续加速，舒服买点减少，资金转找补涨或后排，参与后反馈变差 | 赚钱效应下降，舒服买点减少，参与质量转弱 |
| 三阶段 → 下跌一 | 核心分歧无法有效修复，高中位股批量负反馈，补涨失去溢价 | 亏钱效应系统性爆发 |
| 下跌一 → 下跌二 | 高位风险已较多释放，接力意愿下降，新增极端负反馈减少 | 从恐慌扩散转向亏钱效应逐渐衰竭 |
| 下跌二 → 新启动点 | 新方向不跟旧周期下跌，主动上涨形成板块效应，并出现实际参与后的正反馈 | 新的赚钱效应开始孕育 |

### 转二 → 三阶段的重要辅助判据：有没有舒服买点？

“舒服买点”指有实际承接、能说明参与理由和失效条件、无需因买不到核心而被迫降低标准的机会。**它不是单纯低价，也不是单纯买得到。**

每天比较以下变化：

1. **核心还能正常参与吗？**仍有换手和分歧承接，还是主要靠一字、缩量加速维持强势？
2. **此前买点有后续正反馈吗？**观察最近实际可以买到的位置，其后续表现是否仍有溢价；当天刚出现的买点不能提前认定次日会赚钱。
3. **分歧后的退出机会还在吗？**修复是否有效，还是开板后承接不足、买到就容易承受亏损？
4. **选股是否开始被迫降级？**是否在三阶段后半场，因为核心买不到，转而寻找补涨、后排或弱转强？

**核心仍有买点，参与后有溢价，分歧后有修复，更符合转二。核心持续加速、舒服买点消失、可参与资金反馈变差，更支持向三阶段切换。**

这是辅助判据，需要结合板块广度、核心承接和负反馈一起看。单只股票一字涨停，或者自己没买到，不足以判定整个主线进入三阶段；缺少舒服买点时，可以先降低参与程度，等待进一步证据。

## 四、仓位与执行纪律

仓位跟随周期证据和买点质量调整，不跟随自己的兴奋程度调整。

| 周期 | 仓位倾向 | 核心任务 |
| --- | --- | --- |
| 启动点 | 低仓试错，确认后再逐步提高 | 识别新方向，验证持续性 |
| 转一 | 从试错逐步转向进攻 | 确认主线，参与有效分歧转强 |
| 转二 | 保持进攻，聚焦核心 | 把握有承接、有后续正反馈的买点 |
| 三阶段 | 逐步降低 | 去弱、兑现、管理已有持仓 |
| 下跌一 | 低仓或空仓 | 防守，控制回撤 |
| 下跌二 | 空仓或极低仓，新信号出现后小仓恢复 | 观察衰竭，跟踪新周期 |

仓位不是固定数字，应结合个人最大可承受回撤、单笔风险、持仓相关性和实际退出条件确定。周期判断不清、买点不成立或负反馈增加时，应降低参与程度。

每笔交易先说明：**所处阶段、选它的理由、买点成立条件、判断失效后的退出安排。**不能用“转二容错率高”拖延处理错误交易，也不能因三阶段核心仍在加速而忽略兑现风险。

## 五、每日复盘检查清单

- [ ] **最重要：龙头是谁？主线是什么？**

- [ ] 当前交易主线处于哪个阶段？证据来自当时盘面还是事后解释？
- [ ] 今天的上涨是否提供了有质量、实际可参与的买点？
- [ ] 核心是否仍有正常换手、分歧承接的买点？
- [ ] 最近实际可参与的交易，后续是否有溢价？正反馈在扩散还是收缩？
- [ ] 炸板或分歧后是否仍有修复？亏钱效应是否开始扩散？
- [ ] 是否已进入三阶段后半场，却仍准备做补涨、弱转强，或因核心买不到而降低标准去做后排？
- [ ] 当前仓位是否符合阶段证据？下一步应试错、进攻、兑现还是防守？
- [ ] 什么新信号会推翻当前判断？出现后如何处理持仓？

> [!important] 最终执行口诀
> **启动试错，转一确认，转二抓可参与的赚钱效应；三阶段管持仓，后半场不做补涨、不做弱转强、不降低标准做后排；下跌一防守，下跌二等衰竭与新方向。**
